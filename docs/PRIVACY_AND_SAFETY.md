# Privacy and Safety Notes

## Demo data

MuleShield is a hackathon prototype. Demonstration transaction activity is simulated and should not contain real customer financial information.

## Contact form

The website contact form is designed to collect only:

- Name
- Email
- Message
- Consent choice
- Submission timestamp

The form does not request:

- Card numbers
- UPI PINs
- OTPs
- Passwords
- Bank account credentials
- Authentication secrets

## Payment demo

The payment section is a simulated risk-gated workflow. It does not transfer real funds.

## Third-party services

The prototype may use hosted fonts and the Hatchable hosting platform. Production deployment should review all third-party services, cookies, analytics, embeds, retention periods, and data-processing terms before collecting real user data.

## Security scope

This repository does not represent a production banking security implementation. Real financial integrations require security review, authentication, authorization, audit controls, encryption, monitoring, incident response, and applicable regulatory compliance.
