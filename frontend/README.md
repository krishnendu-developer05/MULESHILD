# Frontend source

The deployed frontend is the code in the public directory:

- public/index.html — page structure and content
- public/theme.css — visual system and responsive layout
- public/app.js — client-side behavior
- public/krishnendu-roy.jpg — founder image used by the deployment

This project uses browser-native HTML, CSS and JavaScript for the deployed showcase rather than a generated React build. The architecture documentation describes React/TypeScript as a possible production expansion, not as code currently deployed.
